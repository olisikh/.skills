# Notes

This skill intentionally keeps device-delivery details out of the conversion wrapper. For a first-generation Paperwhite (EY21), use AZW3 for USB sideloading. Use EPUB as the source for Send to Kindle/email only when Amazon's personal-document service still supports the registered device.

The conversion is reflowable. PDFs that are scans or contain unusual multi-column/layout-heavy content may need OCR or a fixed-layout PDF instead; inspect the result rather than assuming every PDF will reflow well.
